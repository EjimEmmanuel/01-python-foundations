pwd: stands for "Print Working Directory". It displays the full path of the directory you are currently working in.

ls: stands for List. It shows the files and folders in the current directory.

cd: stands for Change Directory. It is used to move from one folder to another within the file system.

mkdir:stands for "Make Directory". It creates a new folder at the specified location

touch: it is used to create a new empty file, and it is also used to create multiple files

cat: It is commonly used to display the contents of a file directly in the terminal.
