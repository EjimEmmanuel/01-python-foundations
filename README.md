# Stone Lines Terminal Edition

Stone Lines Terminal Edition is a two-player strategy game played in the terminal. Players take turns placing and moving stones on a board, aiming to form a line of three stones to win.

## Rules and Phases
The game has two phases:

- **Placement Phase:** Players take turns placing their stones on empty positions on the board.
- **Movement Phase:** After each player has placed three stones, players take turns moving their stones to available positions to form a line of three.

The first player to form a line of three stones wins the game.

## Requirements
- Python 3.13 or a compatible version.
- Required Python packages, including Rich.
- A terminal to run the game.

## Installation
Clone or download the project and navigate to the project directory. Create and activate a virtual environment, then install the required dependencies.

## How to Launch
Activate the virtual environment and run:

```bash
source .venv/bin/activate
```

## Running Tests
To run the test suite, execute:

```bash
pytest -v
```
