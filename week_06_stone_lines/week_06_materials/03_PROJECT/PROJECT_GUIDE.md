# Week 6 Project Guide — Stone Lines Computer Opponent

**Read this only after completing the reading stage and receiving teacher approval.** The reading stage is described in [`../START_HERE.md`](../START_HERE.md).

## What you will build

You will add five decision-making functions so Stone Lines can play against a random computer and a rule-based computer. The prepared game engine and terminal interface already work. Your job is to implement the strategies, not rebuild the game.

## Read the project documents in this order

1. [`PROJECT_OVERVIEW.md`](PROJECT_OVERVIEW.md) — the required result and project boundaries.
2. [`IMPLEMENTATION_RULES.md`](IMPLEMENTATION_RULES.md) — exact action formats, strategy priorities, scoring, and tie-break rules.
3. [`TASK_00_ORIENTATION.md`](TASK_00_ORIENTATION.md) — understand the prepared codebase and run its baseline checks before coding.
4. [`TASK_01_RANDOM.md`](TASK_01_RANDOM.md) through [`TASK_06_RELEASE.md`](TASK_06_RELEASE.md) — complete one task at a time, in order.
5. [`FINAL_ACCEPTANCE_CHECKLIST.md`](FINAL_ACCEPTANCE_CHECKLIST.md) — use it for the final demonstration.

The codebase walkthroughs are in [`../04_CODEBASE_GUIDES/`](../04_CODEBASE_GUIDES/). Task 00 tells you when to read them.

## Work only within the assigned scope

- Implement the strategies in [`../../stone_lines/computer.py`](../../stone_lines/computer.py).
- Add your own tests in `../../tests/test_computer.py`.
- Leave the supplied engine, user interface, storage, constants, baseline tests, and challenge tests unchanged unless the teacher approves a change.
- Run commands from the `week_06_stone_lines/` folder; the setup instructions are in its [`README.md`](../../README.md).

Each task ends with a test gate and a teacher checkpoint. Stop for sign-off before moving to the next task. Finish by updating the project README and completing the reflection in [`../05_ASSESSMENT/REFLECTION.md`](../05_ASSESSMENT/REFLECTION.md).
