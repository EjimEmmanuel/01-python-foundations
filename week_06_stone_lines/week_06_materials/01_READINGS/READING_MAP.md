# Week 6 Reading Map

Use these readings throughout the Stone Lines project. Start with Chapters 1–2 before Task 00, then read the chapters named in each task before that task. You do not need to finish all seven chapters before starting the project. Keep notes, answer the chapter exit questions, and return to readings and examples whenever you need to clarify an idea.

| Order | Chapter | What to be able to explain |
|---|---|---|
| 1 | `01_DECISIONS.md` | Rules, priorities, strategies and fallbacks |
| 2 | `02_STATE_AND_ACTIONS.md` | State, legal choices, action tuples, selection versus execution |
| 3 | `03_RANDOM_BASELINES.md` | Random choice, empty lists, baseline comparison |
| 4 | `04_RULES_PRIORITY.md` | Immediate wins, blocking threats, deterministic tie-breaks |
| 5 | `05_HEURISTICS.md` | Numerical action scoring and its limits |
| 6 | `06_AGENTS.md` | Environment, observation, policy, action cycle |
| 7 | `07_RULES_VS_ML.md` | Rules versus learning from examples |

**Suggested rhythm:** Start with Chapters 1–2; read Chapters 2–3 for Task 01, Chapter 4 for Tasks 02–03, Chapter 5 for Task 04, then Chapters 1 and 4–7 for Task 05. This order lets you learn the ideas near the point where you use them. Move at the pace needed for understanding and revisit earlier chapters when useful.

Work through `../02_PRACTICE/PREPROJECT_WORKED_EXAMPLES.md` and `../02_PRACTICE/KNOWLEDGE_CHECK.md` as practice while reading. Review the full knowledge check with your teacher before Tasks 05–06; use missed or unclear answers to choose which chapters to revisit. It is a learning checkpoint, not a gate that requires all seven readings before Task 00 or Task 01.

### How to study a chapter
1. Read the goals and explain any unfamiliar words.
2. Predict the output of each example before executing it.
3. Write out a short explanation in your own words.
4. Complete the chapter's checks on paper/in your notebook.
5. Explain one idea aloud using an example outside Stone Lines.

### What not to do
Do not implement a minimax algorithm, search tree, new GUI, machine-learning model or database. Those are outside Week 6. Task 00 is orientation only; begin strategy coding at Task 01 after its teacher checkpoint.
